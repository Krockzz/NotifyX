# NotifyX Frontend

Public landing page for NotifyX, an event-driven Notification-as-a-Service platform. The frontend uses React Router Framework Mode, React, JavaScript, and Tailwind CSS v4. The backend remains a separate project.

## Development

```sh
npm install
npm run dev
```

The development server is available at `http://localhost:5173`.

## Production build

```sh
npm run build
```

shadcn/ui is configured for JavaScript components in `components.json`; add individual components with the shadcn CLI as the product UI grows.
